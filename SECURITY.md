# Security and responsible use

This repository is for defensive education. It does not provide exploit scripts or automated attack tools.

- Run experiments only on systems you own or have explicit permission to assess.
- Treat the AST scanner as a limited teaching aid, not a complete security product.
- Do not put credentials, API keys, personal data, or production secrets in source control.
- Review current OWASP and framework documentation before using examples in a real application.
- Report suspected vulnerabilities in systems you are authorized to assess through the owner's approved process.
